Privacy

Last updated 14 November 2026

Tea Kadai doesn't collect any data about you. There are no accounts, no ads, no analytics and no tracking.

Your save and settings stay on your computer, in the game's own folder. Share cards you save go to your Desktop (or your Pictures folder in the Mac App Store version), and only leave your computer if you send them somewhere yourself.

Updates

The versions downloaded from GitHub or this website check GitHub for a newer version when they start, and download it if there is one. Like any download, GitHub sees your IP address when this happens; no other information is sent. You can turn this off in Settings with "Update automatically". The Mac App Store version never connects to the internet; the App Store updates it.

Feedback

"Send feedback" opens a new GitHub issue in your web browser, filled in with the game version, your operating system and the day you're on. Nothing is sent unless you choose to post it, and GitHub's own privacy policy covers anything you post there.

This website

This website is hosted by Cloudflare and doesn't use cookies or analytics.
