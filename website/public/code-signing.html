Code signing policy

Windows

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signing starts once SignPath Foundation approves the project. Until then, Windows downloads are unsigned.

Mac

Mac downloads are signed with an Apple Developer ID and notarized by Apple once the developer account is set up. Until then, they're unsigned.

What gets signed

Only builds made by the release workflow on GitHub Actions, straight from the public source code. Every Windows release is approved by hand before it's signed.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Tea Kadai keeps its save file and settings on your computer and doesn't connect to the internet.
