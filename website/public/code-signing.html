Code signing policy

Windows

Windows downloads aren't signed yet. The plan is free code signing through SignPath.io, with a certificate by SignPath Foundation, once they approve the project.

Mac

Mac downloads are signed with an Apple Developer ID (Juge Praveen, team LW385M78LW) and notarized by Apple.

What gets signed

Only builds made by the release workflow on GitHub Actions, straight from the public source code. Once Windows signing starts, every Windows release will be approved by hand before it's signed.

Privacy

Tea Kadai keeps your save file and settings on your computer.

When it starts, the version downloaded from this site checks GitHub Releases for a newer version and, if there is one, downloads it from there. That's an ordinary download request: it doesn't send your save, your settings or anything about you. You can turn updates off in Settings.

The Feedback button opens a new GitHub issue in your browser, filled in with the game version, your operating system and the in-game day. Nothing is sent unless you submit that issue yourself.
